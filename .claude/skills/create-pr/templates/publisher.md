# PR 템플릿 — 퍼블리셔 (마크업/퍼블리싱)

> 이 템플릿은 **초안(draft)**이다. 실제 팀 컨벤션이 확정되면 이 파일을 그 내용으로 갱신하라.
> 프로젝트의 `CLAUDE.md`/`AGENTS.md`에 이미 PR 관련 규칙이 있다면 그쪽이 우선한다.

## 적용 대상

HTML/CSS 마크업, 디자인 시안(Figma 등) 구현, 반응형/접근성 작업. 상태 관리·API 연동 같은 로직 변경이 섞여 있다면 `fe.md` 템플릿도 함께 확인하라.

## PR 제목

```
[PUB] <페이지/컴포넌트명> - <한 줄 요약>
```

## PR 본문 템플릿

```markdown
## 작업 내용
- 구현한 페이지/컴포넌트와 디자인 시안 링크

## 스크린샷 (필수)
- 데스크톱 / 모바일 뷰
- 디자인 시안과 나란히 비교

## 체크리스트
- [ ] 시맨틱 HTML 태그를 사용했다 (div/span 남발 금지)
- [ ] 이미지 alt, 인터랙션 요소 aria-label을 채웠다
- [ ] 키보드 탭 순서·포커스 스타일을 확인했다
- [ ] 주요 브레이크포인트(모바일/태블릿/데스크톱)에서 깨지지 않는다
- [ ] Chrome/Safari에서 렌더링을 확인했다
- [ ] 디자인 시안과 여백·폰트·색상이 일치한다
```

## 리뷰어

디자이너 1인 + 퍼블리셔 리드. (팀 컨벤션이 확정되기 전까지는 스킬 실행 중 사용자에게 리뷰어 지정을 직접 물어본다.)

## 강제하지 않는 것

- 단위 테스트 작성 (로직이 없는 마크업 변경에는 강제하지 않는다)
- 타입 체크 (순수 마크업/스타일 작업이면 생략 가능)
